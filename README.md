# Nas-s-Portfolio

1. Location-based recommendations. Use geofencing and place data (MapKit or Google Places) to detect that you've arrived at a gas station or restaurant. Send a notification or Live Activity saying "Use the Amex Gold here, 4x." You still tap the card yourself. This is the closest legitimate version of your idea.
   Gonna have to justify allow location pretty hard if going with this route

2. Lock screen widgets, Siri, and Shortcuts that answer "best card for X" in one tap.

3. Post-transaction analysis. Shortcuts has a Wallet transaction automation trigger that fires after a tap and exposes merchant, amount, and card. You can log it, compare it to the optimal card, and show "you missed $X in rewards this month." It can't change the card, but it fuels the analytics half of your product.

4. Data aggregation via Plaid or similar, to pull transactions and card terms for missed-rewards analysis and a card optimizer. Many apps already do this, so differentiation matters.
